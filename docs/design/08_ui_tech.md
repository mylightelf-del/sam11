## 3. 아키텍처 — 로직과 표현 분리

```
┌───────────────────────────────────────────┐
│ 표현 계층 (Unity)                            │
│  3D 맵·부대 연출, UI, 입력, 카메라, 사운드       │
└──────────────▲────────────────────────────┘
               │ 명령 / 이벤트
┌──────────────┴────────────────────────────┐
│ 게임 코어 (순수 C#, Unity 비의존)              │
│  맵·헥스, 무장, 내정, 전투, 외교, AI, 이벤트      │
│  결정론적 난수, 저장·불러오기                    │
└──────────────▲────────────────────────────┘
               │
┌──────────────┴────────────────────────────┐
│ 데이터 (JSON)                                │
│  무장, 특기, 진형, 보물, 시설, 기교, 시나리오, 이벤트 │
└───────────────────────────────────────────┘
```

- **게임 코어는 Unity 없이 돌아가야 한다.** 그래야
  - AI 대 AI 자동 대전을 화면 없이 빠르게 돌릴 수 있다 (06 AI 설계서 8장)
  - 규칙을 단위 테스트로 검증할 수 있다
  - 밸런스 수치를 바꾸고 바로 통계를 낼 수 있다
- **결정론**: 같은 시드와 같은 명령이면 같은 결과가 나온다. 리플레이와 버그 재현에 쓴다.

## 4. 3D 표현

### 4.1 카메라와 줌 단계

| 줌 | 보이는 것 |
|---|---|
| 전국 | 수묵 지도. 세력 색 영역, 도시 아이콘, 부대는 깃발 토큰 |
| 지역 | 3D 지형, 도시 모델, 부대는 깃발 + 소규모 병사 |
| 근접 | 병사 군집이 **진형 모양대로** 배치되어 보임 (어린은 비늘꼴, 학익은 날개꼴 등) |

- 진형이 화면에서 바로 보이게 하는 것이 5편 진형 시스템을 3D로 살리는 핵심이다.
- 전투 연출: 공격·전법·연쇄 시 짧은 근접 연출 (끌 수 있음, 빨리 감기 가능).

### 4.2 맵 렌더링
- 200 × 160 헥스 ≈ 3만 2천 칸. 지형을 청크 단위로 나눠 그리고, 줌에 따라 상세도를 바꾼다 (LOD).
- 헥스 격자선은 켜고 끌 수 있다.
- 날씨(비·눈·안개)와 계절(지형 색 변화)을 셰이더로 표현한다.

## 5. UI

### 5.1 주요 화면

| 화면 | 내용 |
|---|---|
| 메인 맵 | 이동, 공격, 도시 선택, 턴 종료 |
| 도시 | 자원, 인구·민심, 시설 슬롯, 내정 명령 |
| 무장 목록 | 정렬·필터, 능력치, 특기, 진형 적성, 관계 |
| 부대 편성 | 주장·부장 선택, 진형 선택 (적성·상성·지형 미리보기), 병력·병장기 |
| 외교 | 세력 관계, 우호도·신용, 외교 항목 |
| 기교 | 계통별 연구 트리 |
| 군단 | 군단 편성, 방침, 상납 비율 |
| 대결 | 설전·일기토 카드 화면 |
| 이벤트 | 수묵 일러스트 + 대사 + 선택지 |
| 편집기 | 신무장 편집기 |

### 5.2 UI 원칙
- **모바일을 처음부터 고려**: 마우스 호버에만 의존하는 정보 금지 (길게 누르기로 대체 가능하게), 최소 터치 크기 확보, UI 크기 조절 옵션.
- **판단 정보 미리보기**: 공격 전에 예상 피해, 상성·지형 보정, 연쇄 가능 여부를 보여준다.
- 수묵화풍 UI: 한지 질감 패널, 먹 붓 글씨 제목, 인장(도장) 모양 버튼.

## 6. 데이터와 모드

### 6.1 데이터 파일
- 무장, 특기, 진형, 전법, 보물, 시설, 기교, 시나리오, 이벤트를 각각 JSON 파일로 둔다.
- 스키마(JSON Schema)로 형식을 검증한다. 신무장 편집기도 같은 형식으로 저장한다.

### 6.2 모드 지원
- `Mods/` 폴더에 모드를 넣으면 기본 데이터에 **추가·덮어쓰기**된다.
- 모드로 바꿀 수 있는 것: 무장, 시나리오, 이벤트, 보물, 수치 밸런스, 무장 얼굴 이미지(PNG)
- 불러오기 순서와 충돌 표시 기능을 둔다.
- (나중) Steam Workshop 연동

## 7. 저장
