### 2.2 패배 조건
- 모든 도시를 잃으면 패배.
- 군주가 죽었는데 후계자가 없으면 패배. 후계자는 미리 지정하거나, 없으면 혈연·충성 순으로 자동 선택한다.

## 3. 이벤트

### 3.1 이벤트 구조 (데이터로 정의)

```
이벤트
├─ 발생 조건: 연도·월, 세력, 무장 소속·위치, 관계, 이전 이벤트 결과, 확률
├─ 연출: 대사, 일러스트
├─ 선택지 (0~3개): 각 선택지마다 결과
└─ 결과: 무장 등용·이탈, 관계 변화, 능력치 강화, 특기 습득, 자원, 다음 이벤트 해금·봉인
```

- 시나리오 데이터와 같은 형식(JSON 등)으로 만들어, 편집과 추가가 쉽게 한다.

### 3.2 이벤트 종류

| 종류 | 예시 |
|---|---|
| 역사 | 도원결의, 삼고초려, 관우 천리행, 적벽 동남풍, 낙봉파 |
| 인물 | 혼인, 의형제, 사제 관계, 무장 간 불화 |
| 재해·민생 | 홍수, 메뚜기떼, 역병, 풍작 |
| 세력 | 작위 수여, 황제 옹립, 한실 관련 |
| 전투 | 일기토 신청 이벤트, 특정 장소 매복 |

### 3.3 선택지 분기 예시

**삼고초려** (유비 세력, 제갈량 재야, 서서 추천 이후)
- 세 번 방문한다 → 3턴 동안 유비 행동 불가, 제갈량 등용 확정, 충성 최대
- 한 번만 방문한다 → 설전으로 등용 판정
- 방문하지 않는다 → 제갈량이 일정 기간 뒤 다른 세력으로 갈 수 있음

**낙봉파** (방통이 특정 위치로 출진, 전사 옵션 ON)
- 진군한다 → 방통 전사 확률 판정
- 길을 바꾼다 → 이벤트 회피, 대신 진군이 늦어짐

- 분기 결과에 따라 역사와 다른 전개(가상 전개)가 이어질 수 있다.

### 3.4 인간관계

| 관계 | 효과 |
|---|---|
| 의형제 | 같은 부대일 때 능력 보정, 한 명이 떠나면 함께 떠날 가능성, 배신 거의 없음 |
| 부부·혈연 | 충성 상승, 등용 쉬움 |
| 친애 | 같은 부대 보정 (04 군사·전투 설계서 6.1과 반대 효과) |
| 혐오 | 같은 부대일 때 부장 보정 0, 한쪽을 중용하면 다른 쪽 충성 하락 |

- 관계는 시나리오 데이터로 정하고, 이벤트로 새로 생기거나 바뀐다.

## 4. 수명과 세대교체

### 4.1 수명 옵션 (게임 시작 시 선택)

| 옵션 | 내용 |
|---|---|
| 사실 | 역사상 사망년 전후로 사망 (±수년 난수) |
| 가상 | 나이에 따른 확률로 사망 |
| 없음 | 수명으로 죽지 않음 (전사·처단은 전사 옵션을 따름) |

### 4.2 세대교체
- 무장 데이터에 부모·형제·배우자 정보를 둔다.
- 자녀는 성인(15세, 안)이 되면 부모가 속한 세력에 등장한다.
- 자녀는 부모와 상성이 가깝고, 일부 특기를 물려받을 수 있다 (안).
- 군주가 죽으면 후계자가 세력을 잇는다. 후계자의 매력·상성에 따라 일부 무장의 충성이 바뀐다.

## 5. 신무장 편집기

| 항목 | 내용 |
|---|---|
| 기본 정보 | 이름, 자, 성별, 출생년, 얼굴 (프리셋 조합) |
| 능력치 | 공개 5종. **총합 상한 옵션** (예: 400 이하) |
| 숨은 값 | 의리, 야망, 상성 |
| 특기 | 목록에서 1~2개 선택 |
| 진형 적성 | 8개 진형 S~C |
| 관계 | 기존 무장과 혈연·의형제·친애·혐오 설정 |
| 등장 | 등장 시나리오, 등장 연도, 위치, 소속 (재야 또는 세력) |

- 만든 무장은 가상 시나리오와 역사 시나리오 양쪽에 넣을 수 있다 (역사 시나리오에는 재야로만 등장, 안).
- 편집 데이터는 파일로 저장해 공유할 수 있다.

## 6. 구현 현황 (M5-1)

`src/Sam11.Core/World/Events.cs`

- 이벤트는 월초마다 판정한다. 잠기지 않았고(`locked`), 아직 일어나지 않았고(`once`), 결정권 세력(`decider`)이 살아 있고, 조건이 맞으면 일어난다.
- 선택지는 결정권 세력의 컨트롤러가 고른다 (AI는 `ai_weight` 가중치, 플레이어 UI도 같은 통로). 결정권 세력이 없으면 가중치로 무작위.
- 조건: `all` `any` `not` `after` `before` `chance` `ruler_of` `owns` `officer_in` `officer_in_faction` `loyalty_lte` `faction_alive` `faction_destroyed` `event_done` `enemy_units_near`
- 결과: `move_capital` `city_population` `city_morale` `destroy_facilities` `transfer_resources`(금·군량·병력·무장 비율) `trust` `friendship` `unlock_event` `give_treasure` `loyalty` `kill_officer` `split_faction` `officer_join` `transfer_city` `pact`
- 모르는 조건·결과는 오류로 멈춘다 (데이터 오타를 조용히 넘기지 않게).
- `split_faction` (세력 분열): 지정한 무장들이 새 세력을 세우고 주동자가 있는 거점을 가져간다. 남은 세력은 `successor`가 잇는다. 게임은 새 세력에 컨트롤러(AI)를 붙인다.
- `officer_join` (무장 합류): 재야·미등장 무장을 세력에 넣는다 (삼고초려). `allow_defect`면 다른 세력 무장도 옮긴다 (관우 천리행). 군주는 옮기지 않는다.
- `transfer_city` (거점 양도): 싸움 없이 거점을 넘긴다 (장로·유종 항복, 백의도강). 병력·물자는 그대로이고, `with_officers`(기본 true)면 그 거점 무장도 귀순한다. 마지막 거점을 바친 세력은 멸망하고 군주는 새 주인의 신하가 된다.

### 6.1 190년 이벤트 효과 (자동 대전 5판 × 10년)

### 6.3 시나리오 밸런스 조정 (자동 대전)
- 184: 처음에는 조정(하진)과 황건 두 세력뿐이라, 조정이 황건을 꺾은 뒤 빈 땅을 모두 먹고 5판 중 2판을 통일했다.
  → `주목 파견` 이벤트(186년 또는 황건 멸망 뒤)로 유언·유표·공손찬·마등·손견·도겸·유우·원술이 각 주에서 자립하고, 낙양 병력 일부를 데려가며, 조정과 3년 정전을 맺는다. 조정과 황건은 친밀도 0으로 시작해 화친하지 않는다.
  → 5판 × 10년: 통일 0판, 조정 평균 도시 31, 유언·손견 60% 생존.
- 전 시나리오 자동 대전 (3판 × 10년, 통일 0판). 10년 뒤 평균 도시 수 상위:

  |---|---|---|
  | 190 | 동탁 15·도겸 11·유언 10·원소 7 | 조조 생존 33% |
  | 194 | 유장 17·유표 13·도겸 9·원소 7 | 무난 |

  | 215 | 조조 33·손권 13·유비 11 | 삼국 정립 유지 |

- AI 이벤트 선택: 성향 보정을 효과 종류마다 한 번만 곱한다 (효과가 많은 선택지가 지나치게 불리하던 문제).
- `split_faction`은 지정 거점(`seat`)을 잃었으면 근처의 다른 거점을 쓰고, 옛 세력의 본거지는 가져가지 않는다.
