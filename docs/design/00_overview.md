# 삼국지 신작 — 기획 개요 (v0.1)

삼국지 5~11의 호평 시스템을 조합한 군주제 전략 시뮬레이션.
시스템(규칙 구조)은 참고하되, 그래픽·음악·무장 능력치 수치 등 데이터와 에셋은 모두 자체 제작한다.

## 1. 확정된 방향

| 항목 | 결정 | 비고 |
|---|---|---|
| 플레이 시점 | **군주제** | 세력 전체를 운영. 무장제(7·8·10)는 제외 |
| 진행 방식 | **11식 헥스 단일 맵 턴제** | 내정·이동·전투가 한 맵에서 이어짐. 1턴 = 10일 |
| 플랫폼 | **Unity** | 2D/3D 표현 방식은 추후 결정 |
| 1차 목표 | **설계 문서 우선** | 시스템별 설계서 완성 후 개발 착수 |
