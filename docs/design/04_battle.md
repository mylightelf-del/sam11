# 04 군사·전투 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 진형 효과 | **상성 + 진형 고유 보정 + 지형 보정** 3중 구조 (5편식) |
| 부대 편성 | 주장 1 + 부장 최대 2. 진형 적성은 **부대원 중 최고 등급** 적용 |
| 전법 | 진형당 3개. 적성 S=3개, A=2개, B=1개 사용 가능 |
| 전법 연쇄 | 11편식 채용 |
| 턴 단위 | **1턴 = 10일** (한 달 3턴) |
| 날씨·지형 | 날씨 5종 + 지형 × 진형 보정 채용 |
| 부대 능력치 | 주장 능력치 + 부장 보정 (높은 값만 20%) |
| 최대 병력 | 통솔 × 100 + 관직 보너스 |
| 기력·사기 | 둘 다 사용. 기력은 전법 자원, 사기는 전투력·도주 |
| 궤멸 처리 | 귀환·부상·포로·전사 판정. 전사는 ON/OFF 옵션 |
| 공성 | 성문·성벽 분리, 성내 백병전 후 함락 |

> 아래 수치는 모두 초안이며 밸런스 테스트에서 조정한다.

## 2. 피해 계산 구조

```
최종 피해 = 기본 피해(공격측 무력·통솔, 병력)
          × 진형 고유 보정(공격측 공격치 / 방어측 방어치)
          × 상성 보정(우위 1.2 / 열세 0.8 / 무관 1.0)
          × 지형 보정(공격측 지형 / 방어측 지형)
          × 날씨 보정
          × 특기·전법 보정
```

## 4. 상성

### 4.1 상성표 (→ 방향이 우위)

- **기본 진형 순환**: 방원 → 어린 → 학익 → 장사 → 방원
  - 방원이 돌파를 막고, 어린이 얇은 날개를 뚫고, 학익이 긴 진을 감싸고, 장사의 반격이 방원을 무너뜨린다.
- **장비 진형**
  - 추행 → 안행 (기병이 사수를 덮침)
  - 방원 → 추행 (창벽이 돌격을 막음)
  - 안행 → 어린, 학익 (밀집 진형을 사격)
  - 공성진: 모든 야전 진형에 열세

### 4.2 상성 행렬 (행 = 공격측, 열 = 방어측)

| 공격＼방어 | 어린 | 학익 | 방원 | 장사 | 추행 | 안행 | 공성진 |
|---|---|---|---|---|---|---|---|
| 어린 | – | 우위 | 열세 | – | – | 열세 | 우위 |
| 학익 | 열세 | – | – | 우위 | – | 열세 | 우위 |
| 방원 | 우위 | – | – | 열세 | 우위 | – | 우위 |
| 장사 | – | 열세 | 우위 | – | – | – | 우위 |
| 추행 | – | – | 열세 | – | – | 우위 | 우위 |
| 안행 | 우위 | 우위 | – | – | 열세 | – | 우위 |
| 공성진 | 열세 | 열세 | 열세 | 열세 | 열세 | 열세 | – |

- 우위 ×1.2 / 열세 ×0.8. 수진은 수상전 전용이라 상성 대상에서 제외 (수진끼리는 무관).

## 6. 부대 편성

- 주장 1명 + 부장 최대 2명
- **진형 적성**: 부대원 중 최고 등급
- **특기**: 부대원 전원의 특기가 적용된다 (중복 특기는 1회만)

### 6.1 부대 능력치 — 주장 + 부장 보정 (확정)

부장은 주장의 약점을 메우는 역할을 한다. 주장보다 높은 능력치만 일부 반영한다.

```
부대 능력치 = 주장 능력치 + Σ max(0, 부장 능력치 − 주장 능력치) × 0.2
```

- 통솔·무력·지력 각각 따로 계산하고, 상한은 100이다.
- 예: 주장 무력 60, 부장 무력 95 → 60 + 35 × 0.2 = **67**
- (안) 주장과 부장이 "혐오" 관계면 그 부장의 보정은 0이다.

### 6.2 최대 병력 (확정)

```
최대 병력 = 주장 통솔 × 100 + 관직 보너스
```

- 예: 통솔 80, 관직 보너스 +3,000 → 11,000명
- 관직 체계는 01 무장 설계서 6장 참고

## 7. 기력·사기 (확정: 둘 다 사용)

### 7.1 기력 (0~100) — 전법 자원
- 전법을 쓸 때 소모한다 (전법당 15~40, 안).
- 매 턴 +5 회복. 아군 거점에 인접하면 +10.

### 7.2 사기 (0~100) — 전투력과 부대 유지

| 사기 | 전투력 보정 |
|---|---|
| 80 이상 | ×1.1 |
| 30~79 | ×1.0 |
| 10~29 | ×0.8 |
| 0 | 혼란 → 다음 턴 도주 판정 |

| 감소 요인 | 증가 요인 |
|---|---|
| 공격을 받아 큰 피해 (연쇄 피해 포함) | 공격·전법 성공 |
| 포위 (인접 적 부대 3개 이상) | 적 부대 궤멸시킴 |
| 군량 부족 | 일기토 승리 |
| 주장 부상·포로, 아군 부대 궤멸 | 아군 거점 인접 (보급) |
| 일기토·설전 패배 | 특정 특기·전법 |

- **혼란**: 1턴 행동 불가, 방어 감소.
- **도주**: 혼란이 풀릴 때 사기가 여전히 낮으면 가장 가까운 아군 거점으로 퇴각한다.

### 7.3 군량
- 부대는 출진할 때 군량을 휴대하고, 매 턴 병력에 비례해 소모한다.
- 군량이 0이 되면 매 턴 사기 대폭 감소, 병력 일부 탈주.
- 아군 거점이나 보급 시설(03 내정)에 인접하면 보충할 수 있다 (안).

## 8. 전법

### 8.1 진형별 전법 (명칭·효과 초안)

| 진형 | 전법 1 (B 이상) | 전법 2 (A 이상) | 전법 3 (S) |
|---|---|---|---|
| 어린 | 돌파 — 대상을 밀고 전진 | 관통 — 직선 2칸 공격 | 난전 — 대상 기력 대폭 감소 |
| 학익 | 협공 — 인접 아군 수만큼 위력 증가 | 포위 — 대상과 인접한 적 전원 공격 | 섬멸 — 혼란 상태 대상에 큰 피해 |
| 방원 | 견수 — 1턴 방어 대폭 증가 | 역습 — 받은 피해 일부 반사 | 고수 — 1턴 연쇄 피해 무효 |
| 장사 | 연격 — 2회 공격 | 유인 — 대상을 1칸 끌어옴 | 선회 — 공격 후 1칸 이탈 |
| 추행 | 질주 — 이동 후 공격 | 돌격 — 대상 2칸 밀어냄 | 유린 — 대상 혼란 |
| 안행 | 일제사격 — 기본 사격 강화 | 화시 — 불화살, 화재 발생 | 난사 — 범위 사격 |
| 공성진 | 충차 — 거점에 큰 피해 | 투석 — 사거리 3 범위 공격 | 정란 — 성벽 위 부대 공격 |
| 수진 | 충돌 — 함선 공격 | 노포 — 사거리 2 사격 | 화공선 — 적 함선에 화재 |

- 전법은 **기력**을 소모한다. 성공률은 공격측 능력치와 상성에 따라 달라진다.

### 8.2 전법 연쇄 (11편식)
- 전법이 성공하면, 같은 대상에 인접한 아군 부대가 자동으로 추가 공격을 한다.
- 연쇄 수가 늘어날수록 피해가 증가한다 (안: 1연쇄 +10%, 최대 +50%).
- 방원의 "고수" 전법이나 특정 특기로 연쇄를 막을 수 있다.

## 9. 날씨

| 날씨 | 효과 |
|---|---|
| 맑음 | 보정 없음 |
| 비 | 화계·화시 불가, 안행 사격 -20%, 이동 비용 +1 (평지·도로 제외) |
| 눈 | 이동력 -2, 겨울에만 발생 |
| 안개 | 시야 1칸, 매복·기습 성공률 증가 |
| 강풍 | 화재 확산 범위 증가, 안행 사거리 -1 (역풍) |

- 계절별 발생 확률이 다르다 (예: 여름 비, 겨울 눈).
- 날씨는 지역 단위로 바뀐다 (안).

## 10. 부대 궤멸과 무장 처리 (확정: 전사 포함, ON/OFF 옵션)

부대 병력이 0이 되면 부대원 무장마다 따로 판정한다.

| 결과 | 기본 확률 (안) | 확률이 늘어나는 조건 |
|---|---|---|
| 귀환 | 60% | 무력 높음, 퇴로가 열려 있음, 추행 진형 |
| 부상 | 20% | 화계·연쇄 피해로 궤멸 |
| 포로 | 17% | 포위된 상태로 궤멸, 성 안에서 궤멸 |
| 전사 | 3% | 일기토 패배, 화재 칸에서 궤멸, 포위 궤멸 |

- **부상**: 일정 턴 동안 출진 불가. 능력치 일시 감소.
- **포로 처리**: 등용 / 해방 / 처단 / 억류 / 포로 교환(외교)
- **전사 옵션**
  - ON: 위 판정대로 전사 가능. 역사 이벤트의 전사(예: 낙봉파)도 발생.
  - OFF: 전사 판정은 "중상"(장기 부상)으로 바뀐다. 처단도 불가능해지고 대신 추방 처리.
  - 게임 시작 시 선택. 진행 중 변경 가능 여부는 미결.

## 11. 공성 — 성문·성벽 분리 (확정)

### 11.1 거점 구조
- 거점은 **성벽 칸, 성문 칸, 성내 칸**으로 이뤄진 여러 헥스 구조물이다. 칸 수와 배치는 02 맵·도시 설계서에서 정한다.
- 성벽과 성문은 각각 내구를 가진다. 성문 내구는 성벽보다 낮다.
- 수비 병력은 성벽 위나 성내 칸에 부대로 배치된다.

### 11.2 진행 순서
1. **포위·공격**: 성벽 위 수비 부대는 사격 보정을 받는다 (안행 130%).
2. **성문 또는 성벽 돌파**: 내구가 0인 성문·성벽 칸은 통로가 된다. 공성진의 "충차"가 핵심이다.
3. **성내 백병전**: 성 안으로 진입한 부대가 수비 부대와 싸운다.
4. **함락**: 성내의 수비 병력이 모두 0이 되면 함락된다.

### 11.3 성내 규칙
- 성내 칸은 새 지형 "시가"로 취급한다.
- 장비 진형 중 **추행·공성진은 성내에서 쓸 수 없다**. 진입 시 기본 진형으로 전환된다.
- 수비측은 성내에서 방어 보정을 받는다 (안: +10%).
- 수비측의 성문 보수, 화계(성문 앞 화재) 같은 수성 행동은 03 내정·05 계략에서 정의한다.

### 11.4 관문·요새
- 관문: 성문 1개 + 성벽으로 이뤄지며 성내 칸은 작다. 통과하려면 함락시켜야 한다.
