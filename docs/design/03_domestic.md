# 03 내정 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 자원 | 11식 자원 + **인구·민심** |
| 내정 명령 | 11식 무장 투입 + **9편식 군단 위임** |
| 기교 | 11식 세력 단위 연구, **진형과 연결** |
| 수입 주기 | 금 매월, **군량은 가을 수확 연 1회** |

## 2. 자원

| 자원 | 단위 | 용도 |
|---|---|---|
| 금 | 세력·도시 | 건설, 생산, 등용, 외교, 계략 |
| 군량 | 세력·도시 | 부대 유지, 원정 |
| 병력 | 도시 | 부대 편성, 거점 수비 |
| 병장기 | 도시 | 장비 진형 편성: 군마(추행), 노(안행), 공성병기(공성진), 함선(수진) |
| 인구 | 도시 | 징병 상한, 수입 기반 |
| 민심 | 도시 | 수입·징병 효율, 반란 |
| 기교 포인트 | 세력 | 기교 연구 |

## 3. 인구와 민심

### 3.1 인구
- 도시별 인구 (안): 대도시 40만~100만, 일반 도시 10만~40만.
- **징병하면 인구가 줄어든다.** 한 번에 뽑을 수 있는 병력은 인구와 민심에 비례한다.
- 매월 자연 증가: 민심이 높을수록 많이 늘어난다. 도시마다 인구 상한이 있고, 시설로 올릴 수 있다.
- 전쟁 피해: 영역 안에서 전투·화재·약탈이 일어나면 인구가 줄어든다.
- (안) 부대를 해산하면 병력 일부가 인구로 돌아간다.

### 3.2 민심 (0~100)

| 민심 | 효과 |
|---|---|
| 80 이상 | 수입 +10%, 인구 증가 빠름 |
| 40~79 | 기본 |
| 20~39 | 수입 -20%, 징병량 감소, 도적 발생 |
| 20 미만 | 반란 위험 (도시 병력 일부가 반란군으로 이탈) |

| 하락 요인 | 상승 요인 |
|---|---|
| 징병 | 순찰 |
| 높은 세율 | 시혜 (군량·금 배급) |
| 영역 안 전투·화재·약탈 | 매력 높은 태수 |
| 도시 함락 직후 | 특정 시설·특기 |

### 3.3 세율 (안)
- 세력 전체에 저·중·고 3단계로 설정한다.
- 고세율은 금 수입 +30%에 매월 민심 하락, 저세율은 그 반대.

## 4. 수입과 소비

| 시기 | 내용 |
|---|---|
| 매월 1턴째 | **금 수입** = 시장 계열 시설 + 인구 × 세율 × 민심 보정 |
| 매월 1턴째 | **군량 소비** = 병력 수에 비례 (도시 병력 + 출진 부대) |
| **9월 1턴째** | **가을 수확**: 1년치 군량 수입 = 농장 계열 시설 + 인구 × 민심 보정 |

- 가을 수확 전후로 군량 사정이 크게 바뀐다. "추수 전에 군량이 바닥난다", "추수 직후에 원정한다" 같은 계절 전략이 생긴다.
- **군량 저장 상한**: 곡창 시설로 정한다. 상한을 넘는 수확분은 버려지거나 팔아야 한다.
- 영역 안에서 전투가 벌어지는 중이면 수확이 줄어든다 (안).

## 5. 시설 (고정 슬롯)

### 5.1 시설 목록 (초안)

| 분류 | 시설 | 효과 | 단계 |
|---|---|---|---|
| 경제 | 시장 | 금 수입 | 1~3 |
| 경제 | 조폐 | 인접한 시장의 수입 증가 | 1 |
| 경제 | 농장 | 가을 수확량 | 1~3 |
| 경제 | 곡창 | 인접 농장 수확량 증가, 군량 저장 상한 증가 | 1 |
| 인구 | 민가 | 인구 상한 증가, 민심 소폭 상승 | 1~2 |
| 군사 | 병영 | 징병량, 도시 훈련도 상승 | 1~3 |
| 군사 | 마구간 | 군마 생산 | 1~3 |
| 군사 | 공방 | 노 생산 | 1~3 |
| 군사 | 공성창 | 공성병기 생산 | 1~3 |
| 군사 | 조선소 | 함선 생산 (물가 슬롯 전용) | 1~3 |
| 연구 | 서원 | 기교 포인트, 인재 탐색 확률 | 1~2 |
| 방어 | 봉화대 | 시야 확대, 적 접근 경보 | 1 |

- **인접 보너스 (11식)**: 조폐 + 시장, 곡창 + 농장처럼 인접 배치하면 효과가 커진다. 슬롯 배치를 고민하는 재미가 생긴다.
- 업그레이드에는 금, 무장의 행동, 그리고 일부는 기교가 필요하다.
- 시설은 내구가 있고 적 부대가 파괴할 수 있다 (02 맵·도시 설계서 5장).

### 5.2 영역 내 자유 건설 시설 (안)
- 진·보루·화구 같은 **방어 시설**은 슬롯과 상관없이 아군 영역 안 빈 칸에 지을 수 있다 (11식).
- 부대가 행동으로 짓는다. 금이 들고 내구가 낮다.

## 6. 내정 명령 (11식 무장 투입)

무장 1명은 한 턴에 명령 1개를 수행하고, 그 턴의 행동을 마친다.

| 명령 | 효율을 정하는 능력치 | 내용 |
|---|---|---|
| 건설 | 정치 | 슬롯에 시설 건설·업그레이드 (여러 턴 소요 가능) |
| 징병 | 매력 · 통솔 | 인구 → 병력. 민심 하락 |
| 훈련 | 통솔 | 도시 훈련도 상승 → 출진 부대의 초기 사기 |
| 순찰 | 무력 · 매력 | 민심 상승, 도적 진압 |
| 생산 | 정치 | 병장기 생산 (시설 필요) |
| 시혜 | 매력 | 금·군량을 풀어 민심 상승 |
| 거래 | 정치 | 금 ↔ 군량 교환 (시세 변동) |
| 수송 | – | 도시 간 자원 이동 (수송대 출진) |
| 탐색 | 지력 · 매력 | 재야 무장·보물 찾기 |
| 등용 | 매력 + 상성 | 재야·포로·타세력 무장 영입 |
| 수련 | – | 능력치 강화 (01 무장 설계서 5.2) |

## 7. 군단 위임 (9편식)

- 군주가 아닌 무장을 **군단장**으로 임명하고, 도시 여러 개를 군단에 묶는다.
- 군단 소속 도시는 AI가 내정·징병·방어를 자동으로 처리한다.
- **위임 방침**

| 방침 | 행동 |
|---|---|
| 균형 | 시설 건설과 징병을 고르게 |
| 개발 우선 | 시설·인구·민심 위주 |
| 징병 우선 | 병력·병장기 위주, 전선 지원 |
| 방어 | 수비 병력 유지, 방어 시설 건설, 출진 안 함 |
| 공격 | 지정한 목표 거점을 공격 |

- **상납**: 군단 수입의 일정 비율(0~100%)을 본국으로 보낸다.
- 군주는 언제든 군단을 해체하거나 방침을 바꿀 수 있다.
- 야망이 높은 군단장은 충성이 낮을 때 독립할 위험이 있다 (01 무장 설계서 2.2).

## 8. 기교 (11식, 진형 연결)

- 세력 단위로 연구한다. 기교 포인트는 서원, 무장의 탐색·연구 행동, 전투 공적으로 쌓인다.
- 연구에는 기교 포인트와 금이 들고, 여러 턴이 걸린다.

### 8.1 기교 계통 (초안)

| 계통 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 기마 | 군마 생산량 증가 | 추행 이동력 +1 | 추행 전법 "유린" 성공률 증가 |
| 궁노 | 노 생산량 증가 | 안행 전법 "난사" 개방 조건 완화 (A등급부터) | 안행 사거리 +1 |
| 공성 | 공성병기 생산량 증가 | 투석 해금 | 벽력거: 공성진 "투석" 사거리 +1 |
| 수군 | 함선 생산량 증가 | 수진 이동력 +1 | 대형 함선 해금 |
| 진법 | 기본 진형 사기 감소 완화 | 진형 상성 우위 보정 1.2 → 1.25 | 기본 진형 전법 기력 소모 감소 |
| 내정 | 시설 건설 기간 단축 | 인접 보너스 강화 | 민심 자연 회복 |
| 축성 | 성벽·성문 내구 증가 | 성문 자동 보수 | 성벽 위 사격 강화 |

- 상위 단계에는 해당 시설의 단계 조건이 붙는다 (예: 기마 3단계는 마구간 3단계 보유).

## 9. 구현 현황과 확정 수치 (M2)

`src/Sam11.Core/World/Domestic.cs`, 수치는 `data/base/rules.json`의 `economy`.

| 항목 | 공식 (안 → 1차 확정) |
|---|---|
| 매월 금 | (시장 60/110/160 × 인접 보너스 + 인구 × **0.001** × 세율) × 민심 배율 × (1 + 태수 상재) |
| 가을 수확 (9월) | (농장 3,000/5,500/8,000 × 인접 보너스 + 인구 × 0.06) × 민심 배율 × (1 + 태수 농정) |
| 군량 소비 | 병사 1명당 매월 0.1 |
| 군량 상한 | 대도시 20만, 도시 10만, 관문·요새 5만 + 곡창 |
| 군량 부족 | 병력 5% 탈영, 민심 -5 |
| 인구 증가 | 매월 인구 × (0.002 + (민심 − 50) × 0.0001), 상한: 대도시 100만, 도시 40만 + 민가 |
| 민심 | 매월 50 쪽으로 1씩 + 세율 + 태수 인덕 + 민가 |
| 징병 | (1000 + (매력 + 통솔) × 10) × 민심% × (1 + 병영), 한 번에 인구의 5%까지, **도시 병력 상한 = 인구 × 15%**, 병사 1명당 금 0.1, 민심 -4 |
| 훈련 | 5 + 통솔 ÷ 10 (병영·조련 보정) |
| 순찰 | 민심 + 2 + (무력 + 매력) ÷ 40 |
| 생산 | 시설 생산량 × (1 + 정치 ÷ 200) |
| 시혜 | 인구의 1%만큼 군량 → 민심 + 5 + 매력 ÷ 20 |
| 거래 | 금 1 = 군량 **5** × 월별 시세 (8월 0.6배로 비쌈, 9월 1.4배로 쌈), **한 번에 인구의 5%까지** |
| 무장 이동·수송 | 길로 이어진 아군 거점 사이, 즉시 (M3 추가) |
| 등용 | 성공률 = 0.25 + (매력 − 50)/100 + 상성 근접 × 0.3 − (포로면 의리 × 0.03) + 명성 (M3 추가) |

### 9.1 후방 자동 보급 (추가)
- 관문·요새·항구·나루는 자기 영역 도시나 **길로 이어진 같은 세력 거점**에서 매월 군량을 자동으로 받는다 (3개월분이 목표).
- 도시는 자기 몫 3개월분, 중계 거점은 2개월분을 남기고 보낸다. 그래서 낙양 → 호로관 → 사수관처럼 앞쪽으로 전달된다.
- 이어진 아군 거점이 모두 적에게 넘어가면 보급이 끊겨 굶는다.

### 9.2 1년 점검 결과 (명령 없음)
- 일반 도시(인구 20만, 병력 1.2만)는 농장 없이 1년을 겨우 버틴다 — 의도한 긴장감.
- (M3) AI 자동 대전에서 금이 지나치게 쌓여 세금·시세·시설 수치를 조정했다 (06 AI 설계서 9.4).
- 동탁(병력 25만)·유언(13만)은 2년째부터 군량이 부족해진다. 쌓인 금으로 군량을 사거나 병력을 줄이는 판단은 AI(M3)의 몫.
