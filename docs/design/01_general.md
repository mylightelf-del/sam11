# 01 무장 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 능력치 | 공개 5종 + 숨은 값 3종 |
| 특기 | 무장당 기본 1~2개 + 후천 습득 |
| 병종 적성 | **진형 적성**으로 대체 (5편 진형 시스템과 결합) |
| 성장 | 능력치는 고정, 특기만 늘어남. 단, 이벤트·커맨드로 능력치 강화 가능 |

## 2. 능력치

### 2.1 공개 능력치 (1~100)

| 능력치 | 주 용도 |
|---|---|
| 통솔 | 부대 방어, 최대 지휘 병력, 진형 효과 |
| 무력 | 부대 공격, 일기토 |
| 지력 | 계략 성공·간파, 설전 |
| 정치 | 내정 효율, 기교 연구 |
| 매력 | 등용, 외교, 징병·민심 |

### 2.2 숨은 능력치 (플레이어에게 직접 보이지 않음)

| 값 | 범위 | 용도 |
|---|---|---|
| 의리 | 1~15 | 배신·등용 저항. 높을수록 잘 넘어가지 않음 |
| 야망 | 1~15 | 독립·반란 성향, 높은 관직 요구 |
| 상성 | 0~149 (원형) | 군주·동료와의 값 차이가 작을수록 충성 상승 속도와 등용 성공률이 오름. 0과 149는 인접값 |

- 숨은 값은 대사·행동으로 간접적으로 드러나게 한다 (예: "야심이 엿보인다").
- 특정 특기나 기교로 일부 공개 가능 (검토 중).

## 3. 특기

- **기본 특기**: 무장당 1~2개 (일반 무장 1개, 명장급 2개).
- **후천 습득 경로**
  1. 보물 장착 (장착 중에만 유효, 7장)
  2. 이벤트 (사제 관계, 역사 이벤트)
  3. 공적 조건 달성 (예: 화계 성공 N회 → 화신 계열 습득)
- **보유 상한**: 4개 (안)
- **분류**: 전투 / 계략 / 내정 / 외교·인사 / 진형 전용

## 4. 진형 적성

11편의 병종 적성(창·극·노·기병)을 **진형 적성**으로 대체한다.

- 등급: S / A / B / C — **C 등급 진형은 펼칠 수 없다** (확정)
- **병종 개념은 두지 않는다.** 진형이 곧 부대의 성격이다 (확정)
- 진형은 **기본 진형**과 **장비 진형**으로 나뉜다 (확정)

### 4.1 기본 진형 — 병력만으로 편성

| 진형 | 성격 |
|---|---|
| 어린 | 돌파형, 공격 중심 |
| 학익 | 포위형, 다수 대상 공격 |
| 방원 | 방어형, 피해 감소 |
| 장사 | 균형형, 반격 강화 |

### 4.2 장비 진형 — 병력 + 병장기 필요

| 진형 | 필요 병장기 | 성격 |
|---|---|---|
| 추행 | 군마 | 기동형, 고기동·돌격 |
| 안행 | 노 | 원거리형, 사격 |
| 공성진 | 공성병기(충차·정란 등) | 거점 공격 |
| 수진 | 함선 | 수상 전용 |

- 병장기는 출진할 때 병력 수만큼 소모된다. 부대가 궤멸하면 일부를 잃는다 (안).
- 진형 간 상성과 세부 효과는 04 군사·전투 설계서에서 정의한다.

## 5. 성장 — 능력치 고정 + 강화

### 5.1 기본 원칙
- 전투·내정 행동으로 능력치가 오르지 않는다 (11편의 "경험치 → 능력 상승" 제거).
- 성장의 주 축은 **특기 습득**이다.

### 5.2 능력치 강화 수단

| 수단 | 내용 | 제한 (안) |
|---|---|---|
| 수련 커맨드 | 무장이 한 달간 행동 불가, 지정 능력치 +1~2 | 같은 능력 연속 수련 시 효율 감소 |
| 사사(師事) | 능력치가 높은 무장 또는 은자에게 배움 | 스승 능력치를 넘을 수 없음 |
| 이벤트 | 역사·랜덤 이벤트 (예: 병법서 획득) | 무장별 1회성 |
| 보물 | 장착 시 일시 보너스 | 해제하면 사라짐 |

- **강화 상한**: 기본값 +10, 최대 100 (안)

## 6. 관직 — 성장 요소 (확정)

군주가 공적이 쌓인 무장에게 관직을 내린다. 관직은 능력치 대신 무장이 강해지는 또 하나의 축이다.

### 6.1 무관 관직 (초안)

| 등급 | 예시 관직 | 최대 병력 보너스 | 정원 (안) | 필요 군주 작위 (안) |
|---|---|---|---|---|
| 1 | 교위·도위 | +1,000 | 제한 없음 | 없음 |
| 2 | 잡호장군 (편장군·비장군 등) | +2,000 | 10 | 주목 |
| 3 | 사방장군 (전·후·좌·우) | +3,000 | 4 | 공 |
| 4 | 사정·사진장군 | +4,000 | 8 | 왕 |
| 5 | 대장군·표기·거기장군 | +5,000 | 각 1 | 황제 |

- **공적**: 전투(적 격파·거점 함락), 내정, 계략 성공으로 쌓인다.
- **충성**: 관직을 받으면 충성이 오른다. 야망이 높은 무장은 공적에 비해 관직이 낮으면 불만이 쌓인다.
- **군주 작위**: 세력 규모(도시 수 등)에 따라 오르며, 임명할 수 있는 관직 상한을 정한다.

### 6.2 문관 관직 (검토 중)
- 내정·계략 보너스를 주는 문관 계통을 따로 둘지 검토한다.

## 7. 보물 (5편식, 종류별 장착)

- 무장은 **종류별로 1개씩** 보물을 장착한다 (확정). 최대 4개.
- 탐색, 이벤트, 포로·멸망 세력에게서 얻는다. 군주가 하사하면 충성이 오른다.

| 종류 | 주 효과 | 예시 |
|---|---|---|
| 무기 | 무력 +, 일기토 특수 카드 | 청룡언월도, 장팔사모, 방천화극 |
| 명마 | 이동력 +, 추행 적성 상승 | 적토마, 적로, 절영 |
| 병법서 | 통솔·지력 +, 전법·진형 관련 특기 | 손자병법, 맹덕신서, 둔갑천서 |
| 기물 | 정치·매력 +, 내정·외교 특기 | 옥새, 청낭서, 동작대 관련 기물 |

- 능력치 보너스로도 100을 넘을 수 없다.
- 보물로 얻은 특기는 장착 중에만 유효하고, 특기 상한 4개에 포함하지 않는다 (안).
- 옥새 같은 특수 보물은 세력 효과(작위 상승 조건 완화 등)를 가진다 (안).
