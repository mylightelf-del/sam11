# 01 무장 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 능력치 | 공개 5종 + 숨은 값 3종 |
| 특기 | 무장당 기본 1~2개 + 후천 습득 |
| 병종 적성 | **진형 적성**으로 대체 (5편 진형 시스템과 결합) |
| 성장 | 능력치는 고정, 특기만 늘어남. 단, 이벤트·커맨드로 능력치 강화 가능 |

## 2. 능력치

### 2.1 공개 능력치 (1~100)

| 능력치 | 주 용도 |
|---|---|
| 통솔 | 부대 방어, 최대 지휘 병력, 진형 효과 |
| 무력 | 부대 공격, 일기토 |
| 지력 | 계략 성공·간파, 설전 |
| 정치 | 내정 효율, 기교 연구 |
| 매력 | 등용, 외교, 징병·민심 |

### 2.2 숨은 능력치 (플레이어에게 직접 보이지 않음)

| 값 | 범위 | 용도 |
|---|---|---|
| 의리 | 1~15 | 배신·등용 저항. 높을수록 잘 넘어가지 않음 |
| 야망 | 1~15 | 독립·반란 성향, 높은 관직 요구 |
| 상성 | 0~149 (원형) | 군주·동료와의 값 차이가 작을수록 충성 상승 속도와 등용 성공률이 오름. 0과 149는 인접값 |

- 숨은 값은 대사·행동으로 간접적으로 드러나게 한다 (예: "야심이 엿보인다").
- 특정 특기나 기교로 일부 공개 가능 (검토 중).

## 3. 특기

- **기본 특기**: 무장당 1~2개 (일반 무장 1개, 명장급 2개).
- **후천 습득 경로**
  1. 보물 장착 (장착 중에만 유효)
  2. 이벤트 (사제 관계, 역사 이벤트)
  3. 공적 조건 달성 (예: 화계 성공 N회 → 화신 계열 습득)
- **보유 상한**: 4개 (안)
- **분류**: 전투 / 계략 / 내정 / 외교·인사 / 진형 전용

## 4. 진형 적성

11편의 병종 적성(창·극·노·기병)을 **진형 적성**으로 대체한다.

- 등급: S / A / B / C — **C 등급 진형은 펼칠 수 없다** (확정)
- **병종 개념은 두지 않는다.** 진형이 곧 부대의 성격이다 (확정)
- 진형은 **기본 진형**과 **장비 진형**으로 나뉜다 (확정)

### 4.1 기본 진형 — 병력만으로 편성

| 진형 | 성격 |
|---|---|
| 어린 | 돌파형, 공격 중심 |
| 학익 | 포위형, 다수 대상 공격 |
| 방원 | 방어형, 피해 감소 |
| 장사 | 균형형, 반격 강화 |

### 4.2 장비 진형 — 병력 + 병장기 필요

| 진형 | 필요 병장기 | 성격 |
|---|---|---|
| 추행 | 군마 | 기동형, 고기동·돌격 |
| 안행 | 노 | 원거리형, 사격 |
| 공성진 | 공성병기(충차·정란 등) | 거점 공격 |
| 수진 | 함선 | 수상 전용 |

- 병장기는 출진할 때 병력 수만큼 소모된다. 부대가 궤멸하면 일부를 잃는다 (안).
- 진형 간 상성과 세부 효과는 04 군사·전투 설계서에서 정의한다.

## 5. 성장 — 능력치 고정 + 강화

### 5.1 기본 원칙
- 전투·내정 행동으로 능력치가 오르지 않는다 (11편의 "경험치 → 능력 상승" 제거).
- 성장의 주 축은 **특기 습득**이다.

### 5.2 능력치 강화 수단

| 수단 | 내용 | 제한 (안) |
|---|---|---|
| 수련 커맨드 | 무장이 한 달간 행동 불가, 지정 능력치 +1~2 | 같은 능력 연속 수련 시 효율 감소 |
| 사사(師事) | 능력치가 높은 무장 또는 은자에게 배움 | 스승 능력치를 넘을 수 없음 |
| 이벤트 | 역사·랜덤 이벤트 (예: 병법서 획득) | 무장별 1회성 |
| 보물 | 장착 시 일시 보너스 | 해제하면 사라짐 |

- **강화 상한**: 기본값 +10, 최대 100 (안)
