# 02 맵·도시 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 거점 수 | 도시 약 50 + 소거점(관문·항구·나루·요새) 약 50 = **약 100** |
| 도시 크기 | **등급별 차등**: 대도시 19칸, 일반 도시 7칸, 관문·소거점은 소형 구조 |
| 영토 | **도시 영역(11식) + 보급선** |
| 시설 배치 | **11식 고정 슬롯** (도시 주변 정해진 칸에 건설) |

## 2. 맵 규격 (안)

- 헥스 단일 맵. 전략·내정·전투가 모두 이 맵에서 이뤄진다.
- 크기: 약 **200 × 160 헥스** (안). 1칸은 대략 반나절 행군 거리로 본다.
- 범위: 중원 전역 + 요동 일부, 서량, 남만 일부, 교주(베트남 북부) 일부.

### 2.1 지형 종류

| 지형 | 특징 |
|---|---|
| 평지 | 기본 지형 |
| 도로 | 이동 비용 감소. 주요 도시를 잇는다 |
| 숲 | 이동 비용 2, 매복 유리 |
| 산 | 이동 비용 3, 고지 보정. 추행·공성진 진입 불가 |
| 습지 | 이동 비용 3 |
| 강 | 수진만 이동. 나루에서 육상↔수상 전환 |
| 바다 | 수진만 이동. 항구에서 전환 |
| 여울 (안) | 육상 부대가 건널 수 있는 얕은 강. 이동 비용 3, 방어 감소 |
| 시가 | 성내 칸 |
| 성벽 / 성문 | 거점 외곽 칸. 내구를 가진다 |

- 지형 × 진형 보정은 04 군사·전투 설계서 5장 참고.

## 3. 거점

### 3.1 거점 종류

| 종류 | 수 (안) | 역할 | 헥스 구조 |
|---|---|---|---|
| 대도시 | 8~10 | 정치·경제 중심. 시설 슬롯 많음 | 19칸 |
| 일반 도시 | 40 | 내정·징병 기반 | 7칸 |
| 관문 | 15 | 요충지 봉쇄 (호로관·함곡관·검각·양평관 등) | 성문 + 성벽 일렬 + 성내 1~2칸 |
| 항구 | 15 | 수진 전환, 수상 보급 | 3칸 (성벽 없음, 내구 낮음) |
| 나루 | 10 | 강 도하 지점 | 1칸 (내구 없음, 점거로 소유) |
| 요새 | 10 | 전선 방어 거점 | 7칸 (시설 슬롯 없음) |

- 대도시 후보: 낙양, 장안, 업, 허창, 성도, 건업, 양양, 남피, 하비, 수춘
- 소거점은 **따로 함락해야 한다**. 도시를 차지해도 그 영역 안의 관문·항구가 자동으로 넘어오지 않는다.
- 단, 소속 도시를 잃은 소거점은 고립 상태가 된다: 매 턴 사기·병력 감소 (안).

### 3.2 거점 헥스 구조

**일반 도시 (7칸)**
```
     [벽][문]
   [벽][내][벽]
     [문][벽]
```
- 성내 1칸 = 정청. 수비대가 이 칸에 있다.
- 성벽 4칸 + 성문 2칸.
- 성문이나 성벽 칸 하나를 부수면 성내 칸을 공격할 수 있다.

**대도시 (19칸)**
- 성내 7칸 (중앙 정청 + 주변 6칸 시가) + 외곽 12칸 (성벽 8~9칸, 성문 3~4칸)
- 성내 시가 칸에 수비 부대를 여러 개 배치할 수 있어 시가전이 벌어진다.
- 함락 조건: 성내의 모든 수비 부대 궤멸 + 정청 칸 점거.

**관문**
- 성문 1칸을 성벽 칸이 좌우로 막는 일렬 구조. 성벽 양끝은 산·강 등 통과 불가 지형과 맞닿는다.
- 성내 1~2칸. 관문을 함락해야 통과할 수 있다.

## 4. 영토와 보급선

### 4.1 도시 영역 (11식)
- 맵의 모든 육상 칸은 어느 한 도시의 영역에 속한다.
- 도시를 함락하면 그 영역 전체가 넘어간다 (소거점 제외, 3.1 참고).
- 영역 경계는 시나리오 데이터로 고정한다.

### 4.2 보급선
- **보급 상태**: 부대가 아군 영역 안에 있고, 그 영역의 도시가 포위되지 않았으면 군량을 소모하지 않는다 (안).
- **원정 상태**: 적 영역·중립 영역에 있으면 휴대 군량을 매 턴 소모한다.
- **보급 차단**: 아군 도시가 포위되면 (인접 외곽 칸 절반 이상을 적이 점거) 그 영역의 부대도 원정 상태가 된다.
- **수송대 (안)**: 군량·병장기를 운반하는 비전투 부대. 원정 부대에 인접하면 군량을 보충해 준다.
- 군량이 0일 때의 효과는 04 군사·전투 설계서 7.3 참고.

## 5. 시설 슬롯 (11식)

- 도시 영역 안의 정해진 칸이 **시설 슬롯**이다. 슬롯 위치는 시나리오 데이터로 고정한다.
- 슬롯 수 (안)

| 거점 | 슬롯 수 |
|---|---|
| 대도시 | 18~24 |
| 일반 도시 | 10~14 |
| 항구 | 2 |
| 관문·요새·나루 | 0 |

- 시설은 칸 1개를 차지하고 내구를 가진다.
- **적 부대가 시설을 공격해 파괴할 수 있다.** 전선 근처 시설은 위험하다.
- 영역이 넘어가면 남은 시설도 함께 넘어간다.
- 시설 종류와 효과는 03 내정 설계서에서 정한다.
