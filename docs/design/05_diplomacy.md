# 05 외교·계략·대결 시스템 (v0.1)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 외교 | 동맹·정전·포로 교환·공동 작전·원조 + **종속(칭신)** + **신용** |
| 계략 | **전투 계략 + 전략 계략** 둘 다 |
| 설전 | **카드형 미니게임** + 자동 판정 옵션 |
| 일기토 | **카드형 미니게임** + 자동 판정 옵션 |

## 2. 외교

### 2.1 세력 관계 수치

| 수치 | 범위 | 의미 |
|---|---|---|
| 우호도 | 0~100 (세력 쌍마다) | 두 세력 사이의 관계. 외교 성공률에 반영 |
| 신용 | 0~100 (세력마다) | 모든 세력이 보는 평판. 약속을 깨면 크게 떨어짐 |

- 우호도 상승: 원조, 포로 무상 반환, 공동 작전 완수, 공통의 적
- 우호도 하락: 영역 침범, 계략 발각, 시간 경과(서서히 중립으로)
- **신용 하락**: 동맹 파기, 정전 중 공격, 종속국 공격. 신용이 낮으면 모든 외교 성공률이 떨어진다.

### 2.2 외교 항목

| 항목 | 내용 | 기간 (안) |
|---|---|---|
| 동맹 | 서로 공격 불가, 영역 통과 가능, 원군 요청 가능 | 무기한 (파기 가능, 신용 하락) |
| 정전 | 서로 공격 불가 | 6개월~1년 |
| 포로 교환 | 포로 맞교환 또는 금으로 몸값 | 1회 |
| 공동 작전 | 동맹 세력과 같은 목표 거점 공격 | 목표 함락 또는 기간 만료까지 |
| 원조 요청 | 금·군량·병장기 지원 요청 | 1회 |
| **종속 (칭신)** | 약소 세력이 강대국의 종속국이 됨 | 종주국이 해제하거나 종속국이 독립 선언할 때까지 |

### 2.3 종속 (칭신)
- 종속국은 매월 공물(금·군량 일부)을 바친다.
- 종주국은 종속국을 공격할 수 없고(공격하면 신용 대폭 하락), 종속국이 공격받으면 원군 요청을 받는다.
- 종속국은 종주국의 적과 동맹할 수 없다.
- 종주국이 세력 쌍 우호도·국력 차이를 만족하면 **흡수(평화 병합)**를 요구할 수 있다 (안).
- 종속국의 국력이 충분해지면 독립을 선언할 수 있다. 신용 하락은 적다.

### 2.4 외교 실행
- 무장을 사자로 파견한다. 성공률은 사자의 정치·매력, 우호도, 신용, 국력 차이로 정해진다.
- 상대가 망설이면 **설전**이 벌어지고, 이기면 성공률이 크게 오른다.

## 3. 계략

### 3.1 전투 계략 (부대 대상, 부대 행동으로 실행)

| 계략 | 효과 | 조건·제약 |
|---|---|---|
| 화계 | 대상 칸과 주변에 화재. 매 턴 피해 | 비 오면 불가, 강풍이면 확산 |
| 교란 | 대상 부대 혼란 (1턴 행동 불가) | |
| 위보 | 대상 부대가 엉뚱한 방향으로 이동 | |
| 매복 | 숲·산에 숨어 있다가 인접 적 기습 (첫 공격 피해 증가, 사기 감소) | 숲·산·안개에서만 |
| 진정 | 아군 혼란 해제 | |

- 성공률: 실행 부대 지력 vs 대상 부대 지력, 거리, 날씨, 특기
- 기력을 소모한다 (전법과 공유).
- **간파**: 지력 차이가 크거나 간파 특기가 있으면 실패하고, 실행 부대가 역으로 혼란에 빠질 수 있다.

### 3.2 전략 계략 (무장 파견, 여러 턴 소요)

| 계략 | 대상 | 효과 |
|---|---|---|
| 유언비어 | 적 도시 | 민심 하락 |
| 이간 | 적 무장 | 충성 하락 (상성 차이가 클수록 잘 먹힘) |
| 매수 | 적 무장 | 충성이 낮은 무장을 금으로 끌어옴 |
| **내응** | 적 도시의 무장 | 공성할 때 성문 1개를 안에서 연다 (내구 0 처리) |
| 첩보 | 적 도시 | 일정 기간 그 도시의 병력·무장·시설 정보 공개 |

- 금이 든다. 실행 무장은 결과가 나올 때까지 행동할 수 없다.
- **발각**되면: 실행 무장이 포로가 될 수 있고, 두 세력 우호도가 떨어진다.
- 내응 성공 조건 (안): 대상 무장 충성 낮음 + 의리 낮음 + 아군 군주와 상성 가까움

## 4. 대결 시스템 — 설전·일기토 공통 틀

설전과 일기토는 **같은 카드 대결 엔진**을 쓰고, 능력치와 카드 이름만 다르게 한다. 개발량을 줄이고 규칙도 한 번만 익히면 된다.

### 4.1 공통 규칙 (안)
- 양쪽에 **기세 게이지**가 있다. 상대 게이지를 0으로 만들거나, 정해진 합이 끝났을 때 더 많이 남은 쪽이 이긴다.
- 매 합마다 손패에서 카드 1장을 동시에 낸다.
- 카드는 3종이 서로 물고 물린다 (가위바위보). 이긴 카드의 수치만큼 상대 게이지가 깎인다.
- 능력치가 높을수록 카드 수치가 크고, 손패가 많다.
- **특기**는 특수 카드로 손패에 들어간다 (예: "언변" 특기 → 설전 특수 카드).
- **자동 판정 옵션**: 능력치 + 특기 + 난수로 즉시 결과를 낸다. 게임 설정에서 설전·일기토 각각 켜고 끌 수 있다.

### 4.2 설전

| 항목 | 내용 |
|---|---|
| 기준 능력치 | 지력 (카드 수치), 정치·매력 (게이지 크기) |
| 카드 3종 | 논리 → 감정 → 위세 → 논리 (→ 방향이 이김) |
| 발생 | 외교, 등용, 항복 권고, 일부 이벤트 |
| 승리 효과 | 외교·등용 성공률 대폭 상승, 항복 권고면 수비 사기 하락 또는 개성 |

### 4.3 일기토

| 항목 | 내용 |
|---|---|
| 기준 능력치 | 무력 (카드 수치), 통솔 (게이지 크기) |
| 카드 3종 | 공격 → 견제 → 방어 → 공격 |
| 합 수 | 최대 5합 (안) |
| 발생 | 인접한 적 부대에 일기토 신청 (기력 소모). 일부 역사 이벤트 |

- **수락·거절**: AI는 무력 차이로 판단한다. 거절하면 그 부대 사기 -10 (안).
- **승리 효과**: 아군 부대 사기 상승, 적 부대 사기 하락
- **패배 무장**: 귀환·부상·포로·전사 판정. 전사는 전사 옵션 ON일 때만 (04 군사·전투 설계서 10장).

## 5. 구현 현황 — 카드 대결 (M5-2)

`src/Sam11.Core/Duel/CardDuel.cs`, 일기토는 `Battle.ChallengeDuel`.

### 5.1 확정 규칙
| 항목 | 값 |
|---|---|
| 합 수 | 5 |
| 기세 게이지 | 일기토: 통솔 × 0.5 + 20 / 설전: (정치 + 매력) ÷ 2 × 0.5 + 20 (일기당천 +10%) |
| 손패 | 3장 + 능력치 30마다 1장, 매 합 새로 받는다 |
| 카드 위력 | (무력 또는 지력 − 40) ÷ 4 + 0~3 |
| 승패 | 상성에서 이긴 카드의 위력 − 진 카드 위력의 30%만큼 상대 기세가 깎인다. 같은 종류면 서로 절반씩 |
| 특수 카드 | 일기당천(일기토)·언변(설전) 특기. 한 번만 쓸 수 있고, **상성을 무시하고 위력으로 겨룬다** |
| 승리 | 기세 0 또는 5합 뒤 남은 기세 비율이 높은 쪽 |
| 자동 판정 | 양쪽 모두 AI가 카드를 고른 결과 (플레이어 입력도 같은 통로: `ICardPicker`) |

### 5.2 조정 과정
- 처음에는 특수 카드가 무조건 이기고 위력 1.5배였다 → 무력 동률인 관우가 장비(일기당천)에게 15%만 이겼다. 상성 무시·위력 비교로 바꿔 38%.
- 카드 위력이 무력 ÷ 8이라 무력 98과 90이 거의 차이 없었다 → 관우가 화웅을 60%만 이겼다. 위력 공식과 진 카드 막기(30%)로 약 67%.

### 5.3 측정한 승률 (2,000판)
| 대결 | 승률 |
|---|---|
| 여포(100) 대 조홍(78) | 99% |
| 조운(96) 대 하후돈(89) | 85% |
| 여포(100) 대 관우(98) | 82% |
| 관우(98) 대 화웅(90) | 66% |
| 안량(93) 대 문추(93) | 55% |
| 관우(98) 대 장비(98, 일기당천) | 38% |
| 설전: 제갈량 대 장비 | 100% |

### 5.4 일기토 (전투)
- 붙어 있는 적 부대에 기력 20을 써서 신청. 양쪽 대표는 부대에서 무력이 가장 높은 무장.
- 상대 대표 무력이 도전자 − 10 이상이면 받는다. 거절하면 그 부대 사기 -10.
- 이긴 부대 사기 +15, 진 부대 사기 -15. 진 무장: 부상 50%, 포로 15%, 전사 10% (전사 옵션 OFF면 중상), 나머지는 무사히 물러남.
- 진 무장이 부장이면 부대에서 빠지고 능력치를 다시 계산. 주장이 사로잡히거나 쓰러지면 부대가 무너진다. **수비대는 주장을 잃어도 무너지지 않고 사기 -20** (성 병력 전부가 일기토 하나로 사라지지 않게).
- AI: 대표 무력 85 이상이고 붙은 적 대표보다 15 이상 높으면 절반 확률로 신청.

### 5.5 설전
- 등용 성공률이 25% 이상인데 실패하면 설전으로 한 번 더. 이기면 등용 성공.
- 외교(M5-3)에서도 같은 엔진을 쓴다.

## 6. 구현 현황 — 외교 (M5-3)

`src/Sam11.Core/World/Diplomacy.cs`, AI는 `src/Sam11.Core/AI/AiController.Diplomacy.cs`.

### 6.1 확정 규칙
| 항목 | 값 |
|---|---|
| 성공률 | 0.3 + ((사자 정치 + 매력) ÷ 2 − 60) ÷ 100 + (우호도 − 50) ÷ 100 + (신용 − 50) ÷ 200. 상대가 원하지 않으면 × 0.15 |
| 설전 | 성공률 20% 이상인데 실패하면, 사자 대 상대 세력 최고 지력 무장의 설전. 이기면 성사 |
| 동맹 | 12개월, 세력당 최대 2개, 우호도 +10 |
| 정전 | 6개월 |
| 선물 | 금 100당 우호도 +1 (최대 +20) |
| 포로 교환·몸값 | 포로가 되기 전 세력을 기억해 돌려준다. 몸값 = 무장 능력치 합 × 10 |
| 원조 | 상대 본거지 금·군량의 20% |
| 종속 | 종속국 → 종주국 매월 금·군량 10%. 서로 싸우지 않는다. 종속 관계는 우호도가 매달 +1 |
| 병합 | 종주국이 우호도 75 이상·국력 3배 이상인 종속국을 평화롭게 흡수 |
| 파기 | 신용 -30, 우호도 -40 |
| 우호도 변화 | 매달 50 쪽으로 1씩, 거점을 빼앗기면 -15, 무장이 사로잡히면 -5 |
| 평화 관계 | 동맹·연합·정전·종속끼리는 길을 막지 않고, 공격할 수 없다 (먼저 약속을 깨야 한다) |

### 6.2 반(反)최강세력 연합 (06 AI 설계서 7장)
- 도시 30% 이상 또는 국력이 2위의 2배 이상인 세력이 있으면, 그 세력과 맞닿은 세력들이 24개월 연합. 조건이 풀리면 해체. ON/OFF는 `rules.json`의 `diplomacy.coalition.enabled`.
- 자동 대전 예: 동탁이 마등·한복을 병합하자 191년 반동탁 연합(유비·유표·도겸), 동탁 사후 반이각 연합.

### 6.3 AI 외교
- 응답: 동맹은 우호도 45 이상·신용 30 이상이고 **두 세력 어느 쪽보다 강한 공동의 적**이 있을 때만. 정전은 상대가 충분히 강하고(0.8배) 내가 다른 곳에서 싸우는 중일 때만.
- 제안 (매달 한 건, 거절당한 제안은 석 달 쉼): 배신(호전·불신 군주), 포로 교환·몸값, 병합, 종속 요청(도시 2개 이하·국력이 위협의 35% 미만), 원조 요청, 동맹(선물로 우호도부터), 정전(양면 전쟁 피하기).

### 6.4 조정 과정 (빠른 판 유지)
- 처음에는 한 판에 동맹이 130~170건 맺어져 서로 칠 상대가 사라졌다 (10년 생존 세력 10.2) → 동맹 상한 2개, 공동의 적 조건 강화.
- 종속 우호도가 50으로 되돌아가 병합이 한 번도 없었다 → 종속 관계는 우호도가 오른다.
- 결과: 10년 뒤 생존 세력 평균 **6.0** (5판: 6·5·6·6·7). 판마다 병합 4~6건, 연합 결성.
